# KikBak

KikBak is a live social platform designed to feel like an online kickback — live television for the web, where the channels are people.

## Concept

When users open KikBak, they see what is live right now. They can continuously scroll through live channels until they find something they want to watch.

Users can browse live categories including:

- 🔴 Live Now
- 🎮 Gaming
- 🎵 Music
- 🏀 Sports
- 🗣️ Talk
- 😂 Comedy
- 🍳 Cooking
- 🎨 Creative
- 📚 Education
- 🌙 Late Night

These categories are for discovering people who are currently live, not libraries of prerecorded content.

## Features

- Live video streaming
- Continuous live-channel discovery
- Individual user channels/pages
- Channel subscriptions
- Live chat
- Private messaging
- Direct live video conversations

## Current Status

KikBak is currently in development. The initial version is being built as a front-end project while the platform's design and functionality are developed.
